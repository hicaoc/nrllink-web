# NRL 平台功能说明 / Feature Specification

> 本文档完整描述 NRL（Network Radio Link）互联平台的系统功能：**Web 前端控制台**（本项目 `nrllink-web`）与 **Go 后端服务**（`nrllink`）。
>
> This document describes the full feature set of the NRL interconnection platform: the web console frontend (`nrllink-web`) and the Go backend service (`nrllink`).

---

## 一、角色与权限体系 / Roles & Permissions

| 角色 | 说明 / Description | 主要能力 / Capabilities |
| --- | --- | --- |
| `ham` | 普通业余无线电玩家 | 登录、注册、设备管理、加入群组、频点浏览、续费、个人中心 |
| `master` | 平台主理人 | ham 全部能力 + 注册审核（与 admin 共用审核入口） |
| `admin` | 系统管理员（超管） | 全部权限，路由角色过滤直接跳过；可管理用户/群组/节点/配置/套餐/角色/日志 |

- 前端路由按 `meta.roles` 动态过滤（`src/store/modules/permission.js`），`admin` 免过滤。
- 行级按钮按 `checkPermission(['admin'])` 控制（如设备编辑的优先级、群组的允许呼号字段）。
- `billing_enabled` 控制「账号续费」菜单显隐（`meta.requiresBilling`）。
- 免登录路由白名单：`/login`、`/register`、`/auth-redirect`、`/universe`、`/serial` 等。

> 补充：后端还内置「测试群组」（未登记设备自动加入，可立即互通）；设备认证关联后自动离开测试群组，普通用户不可改，管理员可改。

## 二、登录与注册 / Login & Registration

### 2.1 登录门户页 `/login`

无需登录即可访问的「门户式」页面：

- **顶部导航**：NRL 官网、固件 OTA、DMR 数字、串口配置工具（`/serial`）、中英文切换、主题皮肤、3D 宇宙入口、登录/注册按钮。
- **顶部统计栏**：在线设备数、在线浏览器（客户端）数、音频订阅数（实时监控面板推送）。
- **三个可拖拽/缩放/关闭/置顶的浮动面板**：
  1. **支持与链接面板**：官网、OTA 固件站、DMR、BH4TDV 设备坊淘宝店、73HAM 安卓 App、NRL 互联 iOS、NRL 工具集 iOS、NRL 桌面版、NRL 保姆（录音/信标）、NRL 微信小程序（二维码）、串口工具、BG4SF 固件、QQ 群等。
  2. **实时呼叫监控面板**：WebSocket 连接 `/ws/calls`，展示房间列表、正在讲话房间、音频订阅数、最近呼叫记录；**点击房间即可订阅/退订语音**，收到 G.711 音频帧经 Web Worker 解码后用 WebAudio 播放，实现浏览器内实时语音监听。
  3. **服务器列表面板**：列出所有平台（服务器）名称、域名、在线数、高峰数，点击跳转对应站点。
- **登录弹窗**：用户名 + 密码，`POST /user/login`，成功后进入控制台。
- **注册弹窗 / 独立路由 `/register`**：呼号（5-6 位大写）、姓名、电话、密码、邮箱、地址、**执照图片上传**（超过 800KB 自动 Canvas 压缩），`POST /user/reg/create`，提交后由管理员审核。

### 2.2 后端认证 / Auth (backend)

- Token 认证：登录签发 token，前端请求头 `X-Token`，后端 `checktoken` 校验。
- 微信生态：公众号回调 `/api/msg/weixin`、`/weixin/phonecode`、小程序登录 `/api/weixin/wxlogin/teacher` 等（平台预留/启用能力）。

## 三、登录后主控制台 / Main Console

### 3.1 仪表盘 `/dashboard`（平台统计）

- 4 张统计卡片：平台设备总数、在线设备、在线浏览器、音频订阅数。
- 内嵌实时呼叫监控面板（同登录页）。
- 接口：`POST /platform/totalstats`。

### 3.2 个人中心 `/profile`

- **用户卡片**：头像、姓名、角色。
- **时间线**：当前用户最近操作日志（25 条）。
- **账号**：编辑头像 URL、DMR-ID（0~4294967295 整数）、MDC-ID（4 位十六进制）、修改密码；`POST /user/profile/update`。

## 四、设备群组模块 / Devices & Groups（角色：ham）

### 4.1 设备列表 `/pub/device`

全网设备数据库查询与管理（管理员可改所有，普通用户可改自己的设备）：

- **筛选**：呼号、群组、搜索、只看在线、表格/卡片视图切换（移动端默认卡片）。
- **信息列**：呼号-SSID（在线/离线标签）、DMR-ID、状态（**接收/发射开关**，独立启用/禁用）、优先级、名称、QTH、当前群组、射频类型、信道频率、设备型号、累计话音时长/流量、最近话音时长/结束时间。
- **行操作**：
  - **编辑**：名称、DMR-ID、所在群组、优先级（仅 admin）、设备型号、射频类型；射频类型=3（Moto3188/3688）时可编辑 16 个信道名称。
  - **修改（参数编辑）**（需设备在线）：`queryDevice` 拉取设备参数后分五组编辑：
    - **IP 与密码**：呼号（仅 admin）、设备编号 SSID、本机 IP/掩码/网关/DNS、目标服务器地址（平台列表或自定义）。
    - **设备设置**：DCD 模式、PTT 使能、PTT 电平、M/Y PTT、监听、模块供电、按键功能、加尾音/消尾音时长滑杆。
    - **Moto 设置**：Moto 信道切换。
    - **1W 模块 / 2W 模块设置**：接收/发射频率、亚音（CTCSS）、音量、静噪、麦克风增益、**中继频点模板下拉**（从 `/relay/list` 套用）。
  - **AT**（需在线）：`AT+READ` 读取设备全部参数，按指令类型渲染控件（服务器下拉、ON/OFF、DCD、PTT_EN、H/L、文本），逐条执行或自定义 `AT+XXX=数据`。
  - **删除**。

### 4.2 群组房间 `/pub/groups`

公共群组浏览与加入：

- 名称搜索；群组卡片网格（显示类型：公共房间/中继互联/设备互联/数模互联/俱乐部/车友会/会议组/私密房间/其他，不同配色）。
- **我要加入**：列出「我的设备」中尚未加入该群的设备，一键把设备 `group_id` 改为目标群。
- **已加入设备**：查看在线数/总数与设备列表。

### 4.3 频点管理 `/pub/relay`

中继频点模板库（供设备参数编辑复用）：

- 筛选、搜索、新增；表格/卡片视图。
- 字段：名称、上行频率、下行频率、发射/接收哑音（CTCSS）、所有者、状态、备注。
- 操作：编辑、删除（管理员或设备所有者）。
- 接口：`/relay/list`、`/relay/create`、`/relay/update`、`/relay/delete`。

## 五、账号续费 / Renewal（角色：ham，需开启计费）

`/renew`

- 显示当前用户呼号、到期时间、「使用中/已到期」状态。
- 套餐卡片（月份、价格，默认选中第一个）。
- **生成微信扫码订单**：`POST /billing/order/create`，展示微信支付二维码，每 5 秒轮询订单状态。
- **我已支付**：`POST /billing/order/query`，成功后刷新账户信息。
- 接口：`GET /billing/info`、`POST /billing/order/create`、`POST /billing/order/query`；后端微信支付回调 `/billing/wechat/notify`（APIv3）。

## 六、系统设置模块 / Administration（角色：master / admin）

### 6.1 群组管理 `/setup/groups`（admin）

维护公共群组：新增/编辑/删除，字段含群名、类型、**允许加入的设备呼号-SSID 列表**（仅 admin 可见）、备注。

### 6.2 节点管理 `/setup/server`（admin）

服务器节点资料：名称、类型（专用服务器/PC/小主机/树莓派/虚拟机/云厂商）、CPU、内存、带宽、IP、域名、UDP 端口、所有者、状态。

### 6.3 服务器配置 `/setup/config`（admin）

平台级配置整包读取与保存（需重启生效），分区编辑：

- **system**：端口、日志路径、许可证、数据库文件、IP 库、呼叫日志路径。
- **web**：路径、端口、ICP 备案号、SSL 证书/密钥。
- **systeminfo**：平台名称、简称、Logo、语言。
- **openai**：base_url、api_key、engine（AI 聊天接入）。
- **aprs**：APRS 服务器、本机地址/端口、呼号、SSID、passcode、经纬度、海拔。
- **weixin**：公众号/开放平台 appid/appsecret、验证码 URL、头像 URL、EncodingAESKey、欢迎语、关键词、告警模板 ID。
- **billing**：启用开关、到期复查间隔、套餐单价、回调 URL、**微信支付**（appid、商户号、APIv3 密钥、证书序列号、私钥路径、回调、商品描述）。
- **platforms**：平台列表表格直接编辑（名称/域名/端口/在线数/峰值），可增删行。
- 接口：`POST /config/get`、`POST /config/update`（YAML 持久化，自动 `.bak` 备份）。

### 6.4 用户管理 `/setup/users`（admin）

平台会员管理：筛选（呼号/姓名电话/角色）、新增、**导出 Excel**；编辑 DMR-ID、MDC-ID、角色多选、账号到期时间、状态、密码、告警通知开关；删除。

### 6.5 注册管理 `/setup/register`（admin / master）

用户注册申请审核：

- 筛选、**导出 Excel**；状态（待审核/已审核）。
- 审核/编辑：查看执照图片（`/user/reg/image/get`），**已审核**把注册转正为正式用户（`/user/reg/add`），或保存修改（`/user/reg/update`）、删除。

### 6.6 收费套餐 `/setup/billing-packages`（admin）

套餐管理：新增/编辑/停用，套餐价格 = 月份 × 月单价自动计算。

### 6.7 角色管理 `/setup/roles`（admin）

角色增删改、权限树（路由权限）。

## 八、3D 别墅宇宙 / 3D Villa Universe（访客可用）

`/universe` —— 基于 Three.js 的沉浸式 3D 场景，把整个 NRL 网络可视化：

- **平台 → 别墅**：每台服务器是一座别墅，在线数影响屋顶发光；DMR 平台特殊配色，别墅间以彩虹光纤相连。
- **群组 → 房间**：房间按群组类型着色。
- **设备 → 3D 模型**：按 `dev_model` 区分盒子/热点/机架/手机等造型。
- **交互**：左键拖拽旋转、右键平移、滚轮缩放、WASD 移动、Q/E 升降；点击别墅进入大厅、Esc 返回；**画质高/低切换**；面包屑导航（山谷 › 别墅 › 大厅 › 房间）。
- **登录面板**：未登录时底部浮出平台选择 + 登录；登录后点击房间按需加载设备列表、点击设备弹出面板查看/更新，每 30 秒自动刷新在线数据。
- 接口：`POST /platform/list`、`GET /platform/info`、`POST /group/list/mini`、`POST /group/device/list`。

## 九、串口配置工具 / Serial Config Tool（访客可用）

`/serial` —— 基于浏览器 **Web Serial API** 直连 USB 串口设备，无需登录：

- **连接栏**：波特率（9600~115200）、连接/断开、状态标签、HTTPS 提示。
- **自动识别设备类型**：发送 `AT+SET=READ`，收到 `HELLO`+128 字节 → **寄存器设备**（NRL 分体电台远程盒子）；否则回退 **AT 指令设备**（`AT+READ=123` 读取全部参数）。
- **AT 指令设备**：
  - 常用设置：呼号（`AT+CALL`）、SSID（`AT+SSID`，写时补足 3 位）、服务器地址（`AT+D_IP`，平台下拉/自定义），一键刷新/写入全部。
  - 高级 AT 列表：`AT+D_IP` 服务器下拉、ON/OFF 类（`AT+APRS/AT+DHCP/AT+DUPLEX/AT+LOOP/AT+PTT_RES`）、`AT+DCD`、`AT+PTT_EN`、`AT+PW/AT+PTT_IO`（H/L），其余文本输入；每条带中文说明与执行按钮。
  - 自定义 AT 指令执行。
- **寄存器设备**（128 字节寄存器编解码）：
  - 设备信息：固件版本（`AT+VER=?`）、本机序列号。
  - 网络设置：DHCP、IP、网关、掩码、DNS。
  - 模式设置：连接方式（CLIENT/SERVER）、设备角色（HOST 机身/PANEL 机头）、电台型号（IC-7100/FT-891/TS-480/IC-2720/IC-2730/FT-7900/D710-V71/IC-706/D-9000/M-802/ICOM F8101 等）、PTT 超时。
  - NRL 服务器：呼号、SSID、服务器地址；202 服务器：远端序列号（14 位十六进制）。
  - 读写协议：`AT+SET=READ`（HELLO 前缀 + 128 字节）、`AT+SET=WRITE` + 128 字节。
- **通信日志**：双向收发记录（→发送/←接收/·系统），最多 500 条，可清空。

## 十、后端核心能力 / Backend Capabilities

> 后端为 Go 编写的 `nrllink` 服务，详见其仓库 [Readme](../nrllink/Readme.md) 与 [系统架构.md](../nrllink/doc/系统架构.md)。

### 10.1 语音互联 / Voice Relay

- **房间（群组）模型**：设备缺省在 0 号内置群组，系统为每用户预设 10 个内置群组；设备只能加入一个组，加入新组自动离开原组。
- **发言机制**：抢占制——先到先得，谁的语音先到谁占转发权，语音结束后 1 秒释放。
- **自动模式切换**（按在线设备数）：
  | 在线设备数 | 模式 |
  | --- | --- |
  | 1 台 | 静默（普通房间不自动录音回放） |
  | 2 台 | 自动全双工（ESP32/App 类终端免按 PTT） |
  | 3 台及以上 | 默认单工抢占（松开 PTT 200ms 释放） |
- **会议模式**：管理员可开启，服务器端 PCM 多路混音，全双工广播，无抢占。
- **998 鹦鹉房间**：每台设备独立录制并回放自己的语音。
- **999 全网互通房间**：发言自动转发至所有互联服务器的 999 房间。

### 10.2 服务器互联与自动发现 / Server Interconnection

- **APRS 机制（主要）**：服务器用业余呼号认证连接 APRS-IS（`rotate.aprs2.net:14580`），上报位置包 + 状态包（在线/高峰），目的地标识 `NRLSRV`；定时查询 `aprs.tv` 获取活跃服务器列表，自动加入互联转发。
- **官网机制（备用）**：启动时及每 3 分钟 POST `/api/platform-servers/report` 上报自身，每 5 分钟 GET `/api/platform-servers` 同步全网列表。
- **节点类型标识**：`NRLSRV`（服务器）/ `NRLBOX`（硬件）/ `NRLAPP`（App）/ `NRLMP`（小程序）。

### 10.3 设备接入与配置下发 / Device Access & Remote Config

- **UDP 60050**：设备语音/控制信令通道（G.711 a-law 语音帧）。
- **TCP 80 / HTTPS 443**：Web 管理后台。
- **远程参数下发**：`/device/change`（通用参数）、`/device/change1w`、`/device/change2w`（射频模块）、`/device/at`（AT 指令）。
- **在线检测 / 状态上报**：心跳、在线设备 map、QTH 位置（`/device/qth*`）。

### 10.4 运营与扩展 / Operations & Extensions

- **计费**：套餐 + 微信支付 Native 下单、回调验签、订单状态查询、到期自动复查（`billing.go`）。
- **AI 聊天**：OpenAI 接口接入（`chatgpt.go`）。
- **APRS 消息**：`AT+AMSG`（≤64 字节）、`AT+WDJD`（坐标）。
- **数据持久化**：SQLite（用户、设备、群组、中继、服务器、注册申请、套餐、订单、操作日志）。
- **QQ/微信小程序**：`NRLMP` 标识，公众号消息处理、模板消息。

## 十二、设备类型与 AT 指令字典 / Device Types & AT Command Dictionary
